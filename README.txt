============================================================
معرض محمد مبروك لبيع وشراء السيارات
نظام ويب متكامل - النسخة الأكاديمية النهائية
============================================================

1) فكرة المشروع
---------------
موقع عربي RTL لمعرض سيارات، مبني بالكامل باستخدام:
HTML5 + CSS3 + Vanilla JavaScript
بدون React أو Bootstrap أو أي Framework خارجي.

2) ترتيب تشغيل النظام
---------------------
الخطوة 01: افتح index.html.
الخطوة 02: من Navbar انتقل بين الرئيسية والسيارات والتقسيط وبيع سيارتك.
الخطوة 03: استخدم البحث الفوري أو الفلاتر.
الخطوة 04: افتح "التفاصيل" لأي سيارة.
الخطوة 05: استخدم حاسبة التمويل داخل التفاصيل.
الخطوة 06: أضف السيارة إلى المفضلة أو المقارنة.
الخطوة 07: المقارنة تدعم حتى 3 سيارات.
الخطوة 08: أضف سيارة جديدة من زر "+ إضافة سيارة جديدة".
الخطوة 09: السيارة الجديدة تحفظ في LocalStorage وتظهر فوراً.
الخطوة 10: تواصل عبر WhatsApp أو استخدم Web Share/Clipboard.
الخطوة 11: قسم "خلّنا نشتري سيارتك" يرسل طلباً عبر WhatsApp.
الخطوة 12: الوضع الداكن/الفاتح يحفظ تلقائياً.
